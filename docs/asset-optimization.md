# CSS and JavaScript assets

The public layout now loads one common stylesheet and one deferred JavaScript
bundle. Home-specific CSS and JavaScript load only on the homepage. Contact and
service-detail scripts load after the common bundle, with `defer`. The recovery
stylesheet loads only on 404/search pages. The ad-audit layout keeps its own CSS
bundle and deferred script.

| Asset | Source bytes | Generated bytes | Reduction |
| --- | ---: | ---: | ---: |
| Common JavaScript, including quote drawer | 620,719 | 380,379 | 39% |
| Contact script | 1,501 | 837 | 44% |
| Homepage script | 1,402 | 533 | 62% |
| Ad-audit script | 7,406 | 4,967 | 33% |
| Common CSS, including local Bootstrap Icons | 1,020,063 | 959,754 | 6% |
| Homepage CSS | 6,240 | 3,747 | 40% |

The previous public layout had 11 stylesheet links. Normal pages now have one;
home and recovery pages have two. Ten common JavaScript files and the inline
quote-drawer script are served in a single bundle. The audit covers local assets,
public/admin templates, inline initialization and referenced tracking SDKs.
Providers load additional scripts at runtime. Their SDKs, inline initialization
and JSON-LD retain their existing loading order.

## Usage audit

* Removed the unused flag-icons stylesheet: no public template references its
  classes. Font Awesome and Bootstrap Icons are both used and are retained.
* Removed the second jQuery load on the contact page.
* Removed duplicate Bootstrap Icons links from the admin layout, keeping the
  last occurrence and its existing version.
* Removed the global admin Sortable load. The team page still loads the same
  version before its synchronous initialization.
* Removed the empty admin `site.js` load. Legacy source files remain on disk for
  compatibility; they are not included in the new bundles.
* Retained Bootstrap, Swiper, AOS, VanillaTilt, Magnific Popup, Nice Select,
  CounterUp and Waypoints. The existing initialization depends on these APIs;
  rich CMS content can also use their selectors. CSS classes are not purged.
* Tracking bootstraps, async provider SDKs and JSON-LD remain in their existing
  order. Admin scripts used by synchronous inline initialization are not deferred.

Bootstrap Icons **1.13.2**, the version served by the previous unversioned CDN
URL at the time of this change, is stored locally with both font formats and its
MIT license. No icon subset is removed. Relative CSS image/font URLs are rebased
to their original resources when bundling. Google Fonts imports are preserved
at the start of the generated stylesheet.

## Build and validation

```powershell
npm ci
npm run build:assets
npm run check:assets
npm run test:assets
npm run test:ad-audit
dotnet test tests/IdeioCreative.Seo.Tests/IdeioCreative.Seo.Tests.csproj --configuration SitemapQa
```

Generated assets are committed so publishing the .NET project does not require
Node on the server. When local Node dependencies are installed, the .NET build
regenerates assets before static-file discovery. Edit the readable source files,
then regenerate; do not edit `.min` or `.bundle.min` files directly.

The generator compares JavaScript syntax trees and CSS selectors, rule order and
declaration values before/after minification. It disables JavaScript compression
and name mangling. Each bundled vendor retains its directive prologue and UMD
window context. Existing unmatched closing braces in the legacy theme CSS are
preserved at the same location, rather than silently repairing error recovery.
License notices are retained.

Runtime checks cover the menu, quote drawer, contact form, reference slider and
ad-audit submission/tracking. HTTP tests cover 11 public routes, dependency order,
asset availability, the icon font and SEO/error responses. Browser surfaces were
unavailable in this environment; an actual visual/browser comparison was not run.
